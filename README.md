## Descrição

Landing page para o sistema de gestão **Pet-SoftWare**, voltado a clínicas veterinárias e pet shops.

A página apresenta:
- Seção sobre o sistema com imagem (`<figure>` e `<figcaption>`)
- Vídeo de demonstração via `<iframe>` do YouTube
- Tabela de planos e preços (`<table>`, `<thead>`, `<tbody>`)
- Formulário de captação de leads com validação nativa HTML5

## Tecnologias

- HTML5 semântico (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- CSS inline para estilização do cabeçalho, navegação e rodapé
- Sem uso de JavaScript ou frameworks externos

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador, ou acesse pelo GitHub Pages.
